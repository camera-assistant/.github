# Security policy

## Reporting a vulnerability

Do not report a vulnerability in a public issue, discussion or pull request. Report it privately instead:

1. Go to the [camera-assistant repository](https://github.com/camera-assistant/camera-assistant).
2. Open the **Security** tab and click **Report a vulnerability**.
3. Fill in the form.

Please include:

- What kind of problem it is and what an attacker could do with it.
- The version or commit, and where in the code the problem is.
- The steps to reproduce it, and any special setup that is needed.
- A proof of concept, if you have one.

We do our best to answer within a week. Please give us 90 days to fix the problem before you make it public.

## Supported versions

There is no release yet. After the first release, only the latest release gets security fixes.

## Scope

In scope:

- The server.
- The web interface.
- The API and sign-in.

Out of scope:

- Vulnerabilities in third-party dependencies. Report those to their maintainers; we update a dependency when a fix is available.
- Problems that need physical access to the machine that runs Camera Assistant.
